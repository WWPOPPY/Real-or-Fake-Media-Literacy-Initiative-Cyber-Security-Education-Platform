## 🌟 About The Project (เกี่ยวกับโครงการ)

ในยุคที่ AI สามารถสร้างภาพและเสียงได้สมจริงจนแยกไม่ออก **Real or Fake** คือแพลตฟอร์มการเรียนรู้รูปแบบเกม (Gamification) ที่จะเปลี่ยนคุณให้เป็น "นักสืบไซเบอร์"

### ✨ Key Features (ฟีเจอร์หลัก)
* **🕵️ Interactive Missions:** ภารกิจสืบสวนกว่า 15 คดี ตั้งแต่คลิปตัดต่อพื้นฐาน จนถึง Deepfake ขั้นสูง
* **🔍 Real Tools Simulation:** จำลองหน้าจอเครื่องมือตรวจสอบเสมือนจริง เช่น Face Scan, Voice Analysis และ Metadata Check
* **🏆 XP & Ranking System:** ระบบสะสมแต้มและเลื่อนยศจาก "Rookie Agent" สู่ระดับ "Grandmaster"
* **📜 Digital Certificate:** รับเกียรติบัตรรับรองความสามารถทันทีเมื่อจบหลักสูตร
